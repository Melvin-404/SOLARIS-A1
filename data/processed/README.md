# Processed Datasets

This directory holds processed, exported tabular datasets (Parquet and CSV) generated by the pipeline feature extraction and labelling stages for Task A and Task B.

Each dataset exported here includes:
- Tabular time-series feature matrices.
- Verified ground-truth labels.
- Temporal window boundaries and GTI segment identifiers.
- Metadata sidecar files (.json) documenting extraction parameters, input file checksums, and random seeds.
