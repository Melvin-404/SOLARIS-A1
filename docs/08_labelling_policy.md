## 2. Decision D-02: Matching Tolerance ($\Delta t_{\text{match}}$) Between Event Timestamps and SoLEXS Samples

## 4. Positive-Window Labelling Rule for Task A (Solar Flare Detection)

### Options Considered:
- **Option 4A:** Any Overlap ($\text{Overlap}(W, [t_{\text{start}}, t_{\text{end}}]) > 0\text{ s}$).
  - *Trade-off:* Maximizes positive sample count; includes marginal windows where a flare only touches a few seconds of the window.
- **Option 4B (Recommended):** Significant Overlap ($\text{Overlap} \ge 50\%$ of window length $W$, or peak timestamp $t_{\text{peak}} \in W$).
  - *Trade-off:* Ensures every positive window contains substantial flaring emission or the flare maximum, reducing label noise.
- **Option 4C:** Strict Full Containment ($[t_{\text{start}}, t_{\text{end}}] \subseteq W$).
  - *Trade-off:* Cleanest physical signal, but excludes all flares longer than window length $W$ (e.g. long-duration events $> 60\text{ s}$).

### Antigravity Recommendation:
- **Adopt Option 4B:** A window is labeled positive ($Y=1$) if at least 50% of the window duration overlaps with an approved event, OR if the verified flare peak epoch falls strictly inside the window.

## 5. Decision D-08: Verified-Negative Labelling Rule (Task A and Task B)

### Mandatory Rule:
**UNKNOWN INTERVALS ARE NEVER NEGATIVES.**
A window may be labeled as a verified negative ($Y=0$) ONLY IF all of the following conditions are satisfied:
1. **No External Event:** No catalogue flare of any class occurs within the window.
2. **Pre-Flare Embargo Buffer ($T_{\text{embargo, pre}}$):** The window must not occur within $T_{\text{embargo, pre}}$ prior to any catalogue flare onset (prevents pre-flare emission leakage into negative sets).
